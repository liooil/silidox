# 命名规范与调研

本文档整理 Silidox 世界中人物、宗门、地区和功法的命名原则。它不是一张可以直接取词拼接的字表，而是用来保证名称来自世界内部的历史、社会关系与命名者视角。

当前 `WORLD.md`、流派卡和人物文档中的多数专名仍是设计代号。除已经明确标记为正式名称的内容外，不应因为代号使用次数较多，就默认它已经成为正典。

## 核心判断

名字可以有寓意，但不应直接概括人物的剧情功能。

目前的部分人物名存在同一种问题：

- “守拙”直接说明人物对无为和克制的思考。
- “待时”直接说明人物等待出剑的机制。
- “问枢”直接说明人物关注系统枢纽。
- “九返”直接说明人物反复重修。
- “停山”直接说明人物与山石和石化的关系。

这些名字适合作为设计阶段的索引，却像是作者读完人物小传后倒推出来的标签。世界中的父母、长辈和师父在命名时通常不知道人物未来会承担什么剧情，因此正式姓名应当首先符合命名者当时掌握的信息。

宗门暂名也有类似问题。“藏锋宗”“逐境门”“牧魂门”“靖异门”都是“核心机制或立场 + 组织后缀”的结构，便于玩家和设计者快速理解，却缺少宗门所在山川、祖师传承、迁徙分裂和自我认同留下的痕迹。

## 类型作品中的常见方法

以下观察来自对《蜀山剑侠传》《诛仙》《凡人修仙传》《仙逆》《大道朝天》《道诡异仙》等仙侠、修真及相邻作品的比较，并参考中国传统姓名与道教宗派资料。它们是创作样本归纳，不是要求所有作品服从的统计定律。

### 本名先像真实姓名

韩立、王林、张小凡、李火旺、井九、赵腊月等名字并不完整说明人物的能力与立场。即使名字具有明显寓意，也往往可以解释为父母愿望、出生情形、家族习惯或日常用词。

“平安”可以是长辈希望孩子活下来的愿望。人物后来一生不得平安，会让名字获得反照，而不是证明命名者预知了剧情。

### 明显意义交给后天称谓

一个人物可以同时拥有：

- 出生时由家庭给予的名。
- 家族行辈或成年后使用的字。
- 入门后由师长给予的法名、道名。
- 本人选择的号。
- 官职、职事和尊称。
- 因功绩、恶名或误解产生的外号。

本名负责把人物放进家庭和时代，后天称谓负责记录人物后来选择的道路。越接近人物完整命题的词，越适合成为道号、外号或后世评价，而不是出生姓名。

### 同一共同体拥有命名规律

宗族、师承和地区会让名称彼此关联。例如同辈共享一个行辈字，僧道法名共享派内字谱，同一地区偏爱某些自然物、祖先名或祈愿词。

这种关联表达的是“谁为他们取名”，而不是“他们分别负责什么剧情”。同门人物可以共享字辈，同时拥有截然不同的性格和命运。

### 宗门名称来自地望与沿革

宗门常见名称来源包括：

- 山、峰、谷、河、湖、城等祖庭地望。
- 创建者、复兴者或某一支祖师。
- 传承经典、核心仪轨或道统概念。
- 建派时发生的历史事件。
- 宗门合并、迁徙、被敕封或被贬称的结果。
- 外界长期使用并最终取代本名的俗称。

现实道教中同时存在以龙虎山、茅山等本山辨认的传统，以及正一、上清、灵宝、龙门等道统和支派名称。小说中的峨眉派、青云门、黄枫谷、青山宗、中州派也首先建立地理或历史印象，不急于解释完整玩法。

### 统一主题是一种例外

《仙剑奇侠传三》主要人物使用景天、雪见、龙葵、紫萱、徐长卿、重楼等药材名称。这样的命名能够成立，是因为它形成了贯穿一组人物的共同审美系统，而不是让每个名字分别复述人物职业。

Silidox 可以在特定地区、家族或宗门内部使用统一主题，但不应让整个世界共享同一套漂亮词库。

## 人物命名规则

### 从命名者开始

正式确定一个人物姓名前，先回答：

1. 谁给这个人取名？
2. 取名时家庭处于什么社会位置？
3. 命名者希望什么，又害怕什么？
4. 当地有什么常见姓氏、行辈、禁忌和发音习惯？
5. 这个名字是否早于人物后来加入的宗门？

如果无法回答这些问题，姓名通常仍然只是作者标签。

### 区分出生名与修行名

凡人家庭所取姓名不应自动带有精准的修行术语。人物入门后可以获得新的法名、道号或职称，但旧名仍可能被家人、故交或敌人使用。

同一个人物在不同关系中被如何称呼，也应成为叙事信息：

- 家人使用乳名或本名。
- 同门使用法名、字或排行。
- 下属使用职事。
- 敌人使用蔑称。
- 史书使用谥号或后世尊称。

玩家听见哪一个名字，可以反映对话双方的关系，而不仅是文本变化。

### 让意义保持一步距离

姓名可以与人物命运相照、相反或偶然重合，但不要直接给出答案。

可接受的间接联系包括：

- 父母希望孩子平安，人物后来选择危险道路。
- 家族统一使用水旁字，人物最终加入火法宗门。
- 道号表达本人希望成为的人，而不是本人已经做到的事。
- 敌人赠予的恶名后来被人物主动接受。

应避免：

- 控制阵法的人名字里必有“枢”。
- 反复重修的人名字里必有“返”。
- 等待出剑的人名字里必有“待时”。
- 维护某种政治理念的人本名直接复述该理念。

### 建立地区姓名表

正式改名以前，先为主要地区建立简短姓名规则：

| 项目 | 内容 |
| --- | --- |
| 常见姓氏 | 本地大姓、移民姓氏、宗门赐姓 |
| 名字长度 | 单名、双名或特殊结构的比例 |
| 行辈规则 | 家族与宗门如何标记同辈 |
| 偏好来源 | 农时、地貌、经典、矿物、器物、植物等 |
| 禁忌 | 避讳的祖师、君主、灾祸和神名 |
| 称呼习惯 | 本名、字、职事、排行何时使用 |

人物分配到地区以后，再按照这些规则改名。不要先独立创造十个“好听的仙侠名字”，再为它们补造地区。

## 宗门命名规则

### 先写创立史，再确定正式名称

每个宗门正式命名前至少确定：

1. 最早在什么地方形成。
2. 第一代门人如何称呼自己。
3. 是否迁徙、分裂、合并或接受过敕封。
4. 当前正式名称由谁承认。
5. 本门、盟友、敌人和凡人是否使用不同称呼。

宗门可以保留多个并行名称：

| 层次 | 示例作用 |
| --- | --- |
| 正式名 | 盟约、碑文和宗门内部使用 |
| 山门名 | 以祖庭所在山川称呼 |
| 流派名 | 描述修行理论，不一定等于组织名称 |
| 俗称 | 凡人和邻近地区使用 |
| 敌称 | 围剿檄文、旧案和仇敌使用 |
| 旧名 | 记录迁徙、分裂或政治变化 |

### 组织后缀应有含义

- `宗`：强调共同道统、祖师和传承正统。
- `派`：强调从既有传统中分出的支系。
- `门`：可以强调师门、门徒网络或较紧密的组织。
- `教`：往往拥有可向广泛信众传播的教义与仪式。
- `观`、`寺`、`宫`、`院`、`府`：首先是机构或驻地，也可能逐渐代指整个势力。
- `山`、`谷`、`岛`：常由山门地望代指组织。

这些不是绝对规则，但选择后缀时应知道它在世界中表达什么，而不是只考虑读音。

## 当前暂名的处理

在正式地理和历史完成前，保留现有名称作为设计索引：

| 当前代号 | 后续处理方向 |
| --- | --- |
| 太衡宗 | 正式名优先来自祖庭、祖师或正统沿革；“太衡”可留作经义、殿名或道号 |
| 靖异门 | 正式名应体现其自认的正统传承；“靖异”可成为职事、戒律、行动名或外界简称 |
| 石胎门 | 可以保留为正式名，也可以成为源于《山纹炼形法》的俗称，取决于创派史 |
| 藏锋宗 | “藏锋”更适合作为功法原则、剑道流派或外界称呼 |
| 逐境门 | “逐境”可作为修行界对其路线的分类或批评性称呼 |
| 牧魂门 | 很适合作为正道围剿后形成的敌称；宗门旧名未必承认自己只以抽魂为本 |

`world/characters.md` 中所有现有人名继续视为暂名。人物的立场、生平和关系可以保留，正式姓名应在人物归属地区、家庭背景和宗门字辈确定后统一替换。

## 命名流程

1. 确定主要地区的地理、历史和语言习惯。
2. 为每个地区建立姓氏、行辈与称呼规则。
3. 补写宗门创立、迁徙和分裂史。
4. 确定宗门正式名、山门名、流派名和外界称呼。
5. 按人物出生时的命名者视角确定本名。
6. 再补充法名、道号、官称和外号。
7. 检查名称是否过度概括人物功能。
8. 在 `WORLD.md`、流派卡、人物文档、游戏文本和资源路径中统一迁移。

## 检查清单

- 这个名字在人物出生或宗门创立的时刻说得通吗？
- 同地区和同家族的名字能看出共同来源吗？
- 不阅读人物小传，名字是否仍像一个真实姓名？
- 去掉名字的字面寓意后，人物是否依然成立？
- 宗门名称是否留下地理或历史痕迹？
- 功能性名称是否更适合成为流派名、道号或俗称？
- 是否所有重要人物都被迫使用同一种诗意风格？
- 正式改名后，旧称是否仍有值得保留的世界内用途？
