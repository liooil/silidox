# 时代人物

本文档收录故事中跨越宗门、国家与阶层的重要人物。姓名、年龄和具体职务目前均为暂定；已经确定的是人物应当拥有独立于主角的生平、立场与行动能力。正式命名应在人物归属地区、家庭与宗门沿革确定后，按照 [`naming-guide.md`](naming-guide.md) 统一完成。

## 人物设计原则

这个时代的英雄不只指战力最高的人，也包括能够组织生产、维持城市、改变制度、保存知识或迫使世界重新思考的人。

- 人物首先属于自己的历史，其次才是某种意识形态的代表。
- 立场必须来自真实经历，不能只由作者安排一句口号。
- 每个人都应当拥有值得尊重的功绩和可能造成伤害的盲点。
- 合作应当围绕具体问题发生，不要求彼此放弃全部观点。
- 角色的转变来自经历、证据和责任，不来自单一好感数值。
- 任何重要人物都可能拒绝玩家、利用玩家、拯救玩家，或在另一条路线中被玩家清除。

## 晏守拙：无为者何时出手

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 太一宗长者 |
| 出身 | 衡朝断界关附近的凡人农户 |
| 立场 | 无为不是不做事，而是不让一时确信造成不可逆后果 |
| 功绩 | 调停持续数十年的宗门争斗，使三地灵脉免于被毁 |
| 盲点 | 对错误干预极为警惕，因而可能低估迟迟不干预造成的伤害 |

### 生平

晏守拙出生于太一宗山下。幼年时当地旱灾，衡朝官府与宗门互相等待对方开仓，父母都死在赈济到来之前。他被发现具有灵根后进入山门，对“身居高位者为何不立即行动”始终怀有疑问。

年轻时，他曾违背师命下山，推翻一名以妖灾为由征收重税的地方王侯。王侯很快败亡，但继承者之间爆发战争，死者远多于此前暴政所害。晏守拙由此不再相信看见恶行便立即挥剑一定能得到更好结果。

数百年后，他以耐心闻名。一次三宗争夺灵脉时，他没有裁定谁对谁错，而是用十余年重新疏导灵脉，让争夺对象不再只能由一家占有。这件事奠定了他的声望，也让他更加相信改变条件胜过惩罚个人。

### 立场与矛盾

晏守拙很早便认为主角不能被现有妖魔鬼怪分类完整说明，却拒绝在证据不足时用正道魁首的声望替它担保。他相信继续观察可以避免一次错误裁决，但异务司与地方百姓必须在他的观察期间承担现实风险。

他与裴照真曾共同处理越境妖灾，理解她为何要求及时决定；裴照真则认为太一宗总能用漫长时间证明自己的审慎，却把等待中的伤亡和问责留给衡朝。

### 可能轨迹

晏守拙可能主持承认主角为社会行动者的公议，也可能直到主角已经不再需要正道承认时才作出决定。后期，他会支持生产方式自然扩散，却反对玩家用力量一次性摧毁全部旧制度；如果他的劝阻只是保护既得利益，曾经的无为也可能成为玩家必须越过的阻力。

## 裴照真：第四十六天以后

| 项目 | 内容 |
| --- | --- |
| 身份 | 衡朝刑部异务司断界关总署甲等巡界使 |
| 出身 | 衡朝青棠镇遗民 |
| 专长 | “怪”类案件的现场勘验、行为建模与诱捕 |
| 立场 | 嫉恶如仇；未知不能代替有罪，但已经证实的恶不能用未知和程序拖延 |
| 功绩 | 十岁时识破器胚·戊，协助异务司将其捕获并终止青棠镇失踪案 |
| 盲点 | 对已知恶行及其包庇者几乎不留情面，容易低估妥协者的处境，也过度相信自己能够控制调查风险 |

若用最脸谱化的一句话评价，裴照真是一个嫉恶如仇的人。她不是没有愤怒，而是极少让愤怒替自己辨认敌人：未知不等于恶，异类不等于恶，拒绝配合也不自动等于恶；但当蓄意伤害、利用弱者或借制度掩盖恶行已经由证据坐实，她会比多数同僚更坚决，也更难接受以大局、体面或程序尚未完备为由继续拖延。

### 生平

裴照真出生于青棠镇一个猎户家庭。她五岁左右，一件后来被异务司编号为“器胚·戊”的有智造物进入镇中。戊先后以游医、木匠和修补匠的身份生活了五年：它替人看病、修屋、制作玩具，也借这些机会记录居民习惯，逐步带走儿童并杀死发现异常的成年人。

衡昭五年秋，裴照真十岁。她六岁的妹妹失踪，儿时同伴沈砚也在追查时遇害。镇民最初把失踪归因于山路、拐子和妖兽，戊还以热心人的身份参与搜寻。裴照真愤怒得想直接杀死所有可疑者，却知道自己既没有力量，也还不知道敌人是谁；她只能把愤怒压进记录，整理戊出现的时间、接触过的家庭、木屑和药味出现的位置，以及每次失踪前后看似无关的修补委托。

妹妹失踪后的第四十六天，她在戊废弃的工棚中找到七枚被磨光的乳齿，其中一枚有妹妹幼时留下的缺口。她不再等待大人相信，独自越过封路找到异务司巡界使，交出记录，并提出用自己引戊重复既有行为。

异务司依据她的观察设伏。戊没有被某种对所有“怪”都有效的术法镇压，而是在重复取信、隔离目标和转移器身时暴露了这一案特有的约束。裴照真作为诱饵活了下来，戊被捕获；青棠镇却因死者、失踪者与长期互疑再也没有恢复，最终只剩空镇和封存案卷。

衡昭六年，十一岁的裴照真被带入异务司，由笔案吏抚养和教习。她先学档案、尸检与地方口供，成年后转入巡界，逐级升为甲等巡界使。她擅长“怪”案，不是因为拥有辨尽万物的神通，而是因为她知道分类失效时仍可以从重复行为、材料痕迹和对象自身的选择中寻找规律。

### 立场与矛盾

裴照真不会要求主角证明“未来永远无害”，但会要求每一项安全承诺具有可观察边界、失效信号和可执行后果。主角每一次学习和升级既可能成为合作证据，也可能使旧有控制条件失效；她会据此重开判断，而不是永久相信第一次结论。

她接到的初始命令是接触、勘验并提出处置建议，不是清除。她会与主角交换信息、要求检查、划定临时边界，也会在出现明确伤害或扩散条件时申请升级授权。她严格履行自己承诺的停战和撤离条件，但不会把一次合作当作案件终结。

她相信异务司的价值在于让处置可以被记录和复核，却也知道卷宗可能把活物压成一个类别。她反对未经调查的私刑，同样警惕“待复核”成为无限期拘束未知对象的方便借口。

她对已经坐实的恶行没有同样耐心。若一个人明知抽魂、诱杀或侵染正在发生，仍为了利益继续维持，裴照真会把“我别无选择”视为需要查证的事实，而不是天然免责。她能够与有罪者合作阻止更大灾难，却不会把合作改写成清白。

### 可能轨迹

她可能最早提出一套让主角取得有限主体资格的临时规则，因为只有承认对方能够承诺，异务司才能真正追究违约；也可能在玩家不断隐藏能力和清除证人后，主张就地清除。

中期社会共识改变后，她仍会主张对主角技术进行审计和限制，但她的依据必须是行为、风险与法律，而不是“非我族类”本身。她也可能发现衡朝试图借异务司之名控制生产技术，继而在忠于制度与忠于职责之间作出选择。无论哪条道路，她都不应因一次被主角救援便放弃整个人生判断。

## 顾待时：谁有权决定这一剑值得

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 藏锋宗内门出身的合击统筹者 |
| 出身 | 依附藏锋宗的守土小城 |
| 立场 | 长期积蓄属于整个共同体，出剑不能只凭持剑者的荣辱与冲动 |
| 功绩 | 违背宗门命令释放百年剑势，斩杀越境妖物并救下故乡全城 |
| 盲点 | 为避免个人冲动而追求精确调度，可能把人的生命压缩成伤害、成本和优先级 |

### 生平

顾待时幼年被选入藏锋宗外门，第一次战斗便因过早出剑只伤未杀，导致同伴死亡。他从此转入内门，用百余年积蓄下一击，希望再也不因判断不足浪费剑势。

后来一头越境妖物袭击他的故乡。宗门判断小城并非战略要地，命令他继续蓄势，等待妖物靠近更重要的灵脉后再出剑。顾待时违令下山，在妖物尚未造成更大威胁前释放全部剑势。城被救下，他却失去宗门数代人期待的战略储备，也让其他地区不得不重新面对没有这一剑保护的风险。

宗门没有处死他，也没有称他为英雄，只取消了他的内门储备身份，让他负责记录外门出剑。顾待时由此发现，问题不只是某次选择对错，而是宗门从未建立一套能够让被保护者参与的出剑规则。

### 立场与矛盾

他最早理解主角的预测和合击调度价值，希望把不同蓄势周期、目标承伤和控制窗口纳入同一系统，让宗门不再只能在“浪费百年一剑”和“坐视小城毁灭”之间选择。

但调度系统必须设定目标价值。顾待时可以反对掌门独断，却仍可能让程序根据人口、产能和战略位置决定哪座城值得获救。沈观年要求凡人参与制定优先级，裴照真则认为面对可能扩大的威胁必须保留快速越权出剑的能力。

### 可能轨迹

顾待时可以建立跨门派合击网络，使藏锋宗成为保护新生产体系的分层火力；也可能把整个战争变成一套看似中立的资源调度，让无人对被放弃者承担责任。他与玩家最终争论的不会是是否使用算法，而是谁能够定义算法优化的目标。

## 梁问枢：没有灵根的基础设施建造者

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 百工城盟水利与阵法维护行会首席工匠，凡人 |
| 出身 | 城外工匠家庭，无灵根 |
| 立场 | 影响公共生存的阵法必须可审查、可替换、可由多人维护 |
| 功绩 | 建立分布式城防节点，使城市不再依赖一名护城修士 |
| 盲点 | 相信技术共同体比政治权力可靠，却忽视行会自身正在形成新的门槛与特权 |

### 生平

梁问枢的父亲负责维护一座供水阵。掌握核心阵图的修士突然失踪后，任何工匠都不敢修改秘传结构，阵法最终失控，淹死包括他父亲在内的数百人。宗门把事故归为维护不当，行会则认为真正原因是关键知识只属于一个人。

梁问枢此后推动所有公共设施保留图纸、修改记录和替代操作者。他没有灵根，无法独立启动高阶阵法，只能把复杂系统拆成许多凡人能够检查的机械与低阶节点。百工城盟的分布式城防由此建立。

### 立场与矛盾

他会把主角视为证明“力量可以存在于系统而非血统”的关键机会，强烈要求公开阵法结构。但他所在的维护行会也通过认证控制职位，拒绝未经训练者修改设施。别人会问：如果宗门垄断秘法是不公，行会垄断资格为何就是安全？

他能与沈观年合作培养凡人维护者，却反对国家独占全部程序；他欣赏岑九返的可重复构筑，也无法接受对方把真实伤亡当作一次失败运行。

### 可能轨迹

梁问枢可以成为程序公开和公共基础设施的主要推动者，也可能在战争压力下建立一个只有少数认证者拥有最高权限的技术寡头体系。他与玩家的冲突不会取决于是否支持自动化，而取决于谁有权理解和修改自动化。

## 沈观年：让权力随人一同老去

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 百年律国末任期执政官，凡人 |
| 出身 | 地方档案吏家庭 |
| 立场 | 世俗权力必须随凡人世代更替，长生者不得永久控制人间决定 |
| 功绩 | 揭露一名供奉跨越四代政府操纵边境战争，推动公共档案制度 |
| 盲点 | 因生命短暂而急于在任内完成改革，可能建立比长生者更难撤销的自动化国家 |

### 生平

沈观年年轻时整理旧档，发现本国与邻国持续百年的边境冲突，每次开战都由不同君主签字，背后建议者却始终是同一名修士供奉。供奉没有篡位，只通过等待、选择性保存记忆和控制情报，让四代凡人统治者重复作出有利于他的决定。

沈观年公开档案，由此进入政坛，并推动官员不得修炼、长期契约必须由新一代重新确认的法律。她并不仇视修士，反而认为不让长生者直接执政，也是在避免他们永远承担一项早已不适合时代的责任。

### 立场与矛盾

她希望把主角的关键程序置于公共机构控制之下，防止任何宗门或个人永久垄断。但主角本身可能比所有本地修士活得更久；从她的制度逻辑看，把基础设施永久交给主角同样危险。

战争临近时，她可能建立覆盖全国的自动调度和防御体系。这能保护凡人政权，也会让她在任期结束前创造一个继任者无法真正关闭的国家机器。

### 可能轨迹

沈观年可以成为限制主角权力最有说服力的盟友，也可能成为最早尝试收归程序与阵法的国家领导者。她与玩家的关系取决于玩家是否愿意建立真正能够脱离主角运行的制度。

## 姬承露：被血统制度排除的血统维护者

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 灵谱诸国大族谱官与实际政务主持者，凡人，无灵根 |
| 出身 | 数代诞生高资质修士的世族主支 |
| 立场 | 家族是凡人与长生力量之间唯一经过时间验证的责任共同体 |
| 功绩 | 通过谱系、婚盟和资源调度结束三族争夺宗门名额的战争 |
| 盲点 | 能够看见制度对自己的不公，却仍把其他人的婚姻与生育视为家族资源 |

### 生平

姬承露出生前，族中根据父母谱系认定她极可能具有上等灵根。检测结果却是一片空白。弟妹被宗门带走后，她留在家族管理田产、婚约与供养，逐渐成为真正维持整个世族运行的人，却始终没有资格继承象征最高地位的族印。

她没有因此否定灵谱制度。一次三大世族因争夺宗门名额濒临战争时，她重新核对数百年婚姻与灵根记录，用互换培养和共同供养结束冲突。在她看来，个体自由无法独自维持跨越数代的修仙投入，只有家族会对尚未出生的人负责。

### 立场与矛盾

主角的程序证明没有灵根的人也能控制超凡设施，这为姬承露提供了她一生未获承认的能力，也可能摧毁她用来保护家族的全部秩序。她倾向于把程序教育纳入世族体系，以长期责任为由限制无家族担保者使用。

她与梁问枢都重视传承和维护，却争论传承主体应当是开放行会还是血缘家族。她也可能支持岳停山要求承受功法代价者分享收益，同时坚持收益应由家族代为管理。

### 可能轨迹

姬承露可以利用新技术拆除灵根等级，也可以把旧灵谱改造成记录程序资格与技术婚盟的新谱系。她最危险的地方不是拒绝变化，而是非常擅长让变化服务于旧家族。

## 杜还生：不请求原谅的改革者

| 盲点 | 把一切伦理问题转化为供应问题，可能用效率掩盖新的伤害与垄断 |

### 生平

杜还生幼年所在村庄毁于正道与魔门的交战。牧魂门收养了他，也教会他抽魂。他曾参与猎取人魂，没有被迫失去意识，也没有把全部责任推给宗门。围剿发生时，他负责保管魂库，亲手消耗其中的人魂维持受伤同门。

战败后，他最早接受主角提出的鸡魂替代方案，不是因为忏悔，而是因为他准确判断继续猎人只会让宗门彻底灭亡。他学习饲料、疫病、屠宰和销售，把过去被视为杂役的凡人生产者纳入宗门核心。

### 立场与矛盾

杜还生不请求受害者原谅，也拒绝用道德表态代替生产转型。他认为只要鸡魂供应尚不能覆盖需求，要求所有门人立即停用人魂就只是让守规矩者先死、强硬派掌权。

这套现实主义能够完成转型，也可能让他接受极端密集养殖、压低凡人工钱或垄断饲料。他结束一种掠夺时，未必会主动阻止另一种剥削。

### 可能轨迹

他可以成为最懂自动化生产的宗门领袖之一，也可能建立一个以生存为理由拒绝任何外部审查的庞大产业。裴照真不会因养鸡便忘记他抽取过的人魂，两人却可能为了阻止拒绝转型的牧魂门强硬派短暂合作。

## 岑九返：把失败变成下一次构筑

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 逐境门多次碎丹重修者 |
| 出身 | 凡人军户，少年时以极薄根基进入宗门 |
| 立场 | 状态可以失去，只要构筑方法和失败记录能够进入下一轮 |
| 功绩 | 完成九次重修并越过前人认为无法重复抵达的境界 |
| 盲点 | 习惯把自己的跌落视为可恢复，也容易误以为组织、城市和死者同样能够重来 |

### 生平

岑九返第一次登上高境界时只用了同门一半时间，也在庆功宴结束前跌回低境。此后每次重修，他都会记录突破前的资源、身体状态和失败位置。早期记录杂乱矛盾，直到主角把它们整理成有依赖关系的构筑步骤，他才第一次看见九轮修行不是九次孤立冒险。

他主动成为逐境门反哺方法的试验者，允许同门检查自己最隐秘的修行过程。反复构筑使他的低层根基逐渐稳固，也让他成为宗门中最了解“如何从废墟重新开始”的人。

### 立场与矛盾

岑九返相信失败不是终点，这让他在后期战争中能够组织迅速恢复的生产与军事网络。但他也可能把撤退、设施损失和人员牺牲称为可以接受的一轮测试。

梁问枢重视他的可重复方法，却会提醒他：程序能够重跑，死者不能。裴照真则欣赏他面对未知威胁的果断，两人可能成为极有效也极危险的战时组合。

### 可能轨迹

他可以发展出真正尊重不可恢复损失的韧性体系，也可能成为不断发动失败战争、相信下一轮必然更好的军事领袖。

## 岳停山：谁承受代价，谁拥有产物

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 石胎门资深弟子，首批接受动态余灵抽取者 |
| 出身 | 山中采石家庭 |
| 立场 | 灵石来自门人身体承担的结晶风险，收益不能只归宗门和商人 |
| 功绩 | 在身体接近完全石化时保存功法运行记录，为主角完成抽取方案提供关键数据 |
| 盲点 | 可能把“承受代价”变成新的资格，鼓励更多弟子主动冒险以换取分配权 |

### 生平

岳停山少年时修炼极快，被视为石胎门复兴希望。灵气结晶最初让她刀剑难伤，后来却逐渐锁死膝、肩和手指。她无法再下山作战后，主动记录每一次结晶扩展，没有用宗门惯常的“心境不坚”解释身体变化。

主角根据这些记录建立动态抽取，岳停山成为第一批避免彻底石化的人。抽出的余灵被压成灵石后，宗门第一次发现过去的绝症也可以成为持续产能。

### 立场与矛盾

商人和长老把灵石视为宗门新资产，岳停山却认为产量直接来自门人身体承担的风险，主张修炼者、维护者和受损者共同拥有收益。她因此组织接受抽取的弟子记录产量与身体代价。

如果风险与收益绑定，贫穷弟子可能主动提高生灵强度，把身体变成灵石来源。岳停山必须决定自己建立的是保护修炼者的共同体，还是一种更精确计算人体损耗的新矿场。

### 可能轨迹

她可以成为新生产关系中最早争取劳动与风险权利的人，也可能在战争中为了灵石供应要求门人承担超过安全线的生灵负荷。她与闻潮生需要合作销售灵石，却会持续争论价格之外是否还有不能交易的代价。

## 闻潮生：没有善意也能合作多久

**待打磨：** 该角色当前设定不令人满意，需要进一步打磨。

| 项目 | 内容 |
| --- | --- |
| 身份 | 万契海市契师、商队组织者与跨宗门经纪人，凡人 |
| 出身 | 因祖辈保护契约背负数代债务的商户家庭 |
| 立场 | 善意会变化，明确的期限、价格和违约后果才允许弱者与强者合作 |
| 功绩 | 组织多个小城共同购买护航，使它们摆脱单一宗门的长期控制 |
| 盲点 | 相信任何关系都能写入契约，容易把无力拒绝者的被迫同意也视为有效选择 |

### 生平

闻潮生家族曾与一名修士签订百年护商契约。修士确实履行保护，却通过复利条款取得商队大部分收益；签约者死后，后代仍无法退出。闻潮生花了二十年寻找契约漏洞，最终联合其他债户一次性买断义务。

她没有因此否定契约，反而认为问题在于凡人缺少理解长生时间尺度的专业能力。她成为契师，为多个小城设计共同采购宗门保护的合同，并以公开竞价迫使保护者降低价格。

### 立场与矛盾

闻潮生会迅速理解程序许可、维护服务和灵气产量的商业价值。她能让主角技术跨越敌对边界扩散，也会主张把每次运行、更新和修复都写成收费项目。

梁问枢认为基础设施不应受无法退出的许可控制；闻潮生则反问，没有稳定收益，谁会承担百年维护责任。岳停山要求把身体代价计入灵石价格，她愿意计算，却未必承认存在不可标价的部分。

### 可能轨迹

她可以建立第一个让凡人与宗门平等追责的技术契约体系，也可能创造一个所有人都依赖、却没有人真正拥有的许可网络。她很少背叛合同，但会毫不犹豫地利用合同没有禁止的空间。

## 群像叙事的阶段

### 前期：相遇与分类

人物围绕主角是否能够交流、能否成为责任主体以及谁有权作出分类和处置发生冲突。合作主要出于生存、调查、交易和地方危机。

### 中期：承认与传播

主角反哺门派并参与生产。人物开始争论谁能获得程序、谁承担事故、主角是否应被承认为社会行动者。原有敌友关系第一次大规模重组。

### 后期：生产关系与战争

人物不再只决定是否接纳主角，而要决定新生产系统由谁控制。早期调查者可能成为限制主角权力的盟友，也可能代表衡朝争夺基础设施控制权。
