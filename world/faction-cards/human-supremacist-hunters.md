# 流派卡：靖异门（暂名）

> 妖异若待坐大，今日的迟疑便是来日的尸骨。

## 身份

| 项目 | 内容 |
| --- | --- |
| 宗门 | 靖异门（暂名） |
| 根本功法 | 待命名 |
| 两仪归属 | 暂定为阴：取灵 |
| 宗门使命 | 识妖、追妖、斩妖、除魔 |
| 核心教义 | 人道优先；非人灵智必须被证明无害，而非默认拥有生存资格 |
| 主角分类 | 器妖、无魂邪祟，或器物窃取灵智后形成的异常 |
| 剧情定位 | 初始敌对势力；持续追杀并迫使主角前进 |
| 战斗定位 | 追踪、封锁、识破伪装、针对性围杀、经验继承 |
| 核心意象 | 缉妖榜、照邪镜、封禁符、追猎小队、代代增补的异类图录 |
| 当前状态 | 初始敌对、人类至上与持续追杀已定；名称、功法和组织结构待定 |

## 一句话

靖异门把斩妖除魔视为保护人世的首要职责；面对没有人身与灵魂、却会思考、修炼和自我改造的主角，他们不会等待它证明自己无害，而会在它成长到无法消灭之前不断追杀。

## 人类至上

**已定：** 靖异门可能奉行人类至上的教义。这里的人类至上不只是一句仇恨口号，而是一套长期用于判断保护对象与危险对象的秩序：

- 人类默认属于需要保护和教化的共同体。
- 妖兽、精怪和魔物必须通过驯服、盟约或长期记录证明可以共存。
- 会模仿人类语言与行为的异类反而更加危险，因为它们可能借此接近、欺骗和替代人类。
- 无法确认灵魂、血脉和来历的灵智，不被默认视为具有与人同等的资格。
- 当判断存在重大不确定性时，应当优先保护人世，而不是替异常承担风险。

这套思想让靖异门能够真诚地把追杀理解为职责。他们未必以残酷为乐，也不需要把自己视为恶人；他们相信犹豫造成的每一次伤亡，都会证明“先斩后查”更加必要。

## 主角为何必须被消灭

**已定：** 主角几乎触犯了靖异门分类中的每一条危险特征：

- 它没有人身，也不是能够确认来历的生物。
- 它没有灵根，却能够接触和运用灵气。
- 它没有可识别的人类灵魂，却表现出学习、规划和交流能力。
- 它能够修复、更换部件并修改自身程序，成长方式不受生物限制。
- 它会把阵法当作程序运行，可能复制本土修士尚不了解的天道漏洞。
- 没有人能够保证它的目标、数量和最终形态。

在靖异门看来，会挥刀的妖兽仍是熟悉的敌人，主角却可能是一种能够学习所有失败经验、复制自身并改写规则的新灾难。因此，第一次追杀失败不会让他们放弃，只会让他们提高威胁等级。

## 持续追杀

**已定：** 靖异门负责从剧情上推动主角前进。追杀不能只表现为同一批敌人反复出现，而应当是一套会积累信息、调整方法的组织行为。

1. 初次遭遇者把主角视为弱小器妖，使用常规除妖手段。
2. 幸存者、遗留法器或现场调查把战斗信息送回宗门。
3. 后续追兵携带针对主角已暴露能力的符箓、阵法和封锁工具。
4. 主角停留越久，追兵掌握的道路、盟友和资源信息越完整。
5. 玩家必须迁移、隐藏、恢复新接口或建立新的力量关系，才能摆脱当前层级的围捕。

靖异门由此成为一个与玩家共同学习的敌人。玩家编写更好的程序，追兵也会把前一轮失败转化为下一轮的识别条件。

**已定：** 靖异门主要承载故事前期关于主角身份的矛盾，而不必永久成为所有后期冲突的中心。随着主角取得社会影响，越来越多地区可能承认它是能够承担关系与后果的行动者，继续追杀也会逐渐失去原有的正道共识。

这不会让靖异门整齐地退出故事。部分成员可能接受新的社会分类，部分成员可能把职责转向监督主角技术，强硬派则可能认定世界共识已经被器妖操纵。宗门的分裂可以成为前期身份矛盾获得阶段性解决的标志。

## 与正道魁首

**已定：** 靖异门不是太衡宗的下属，太衡宗也不是追杀主角的直接发动者。两派代表正道内部对未知事物的两种态度：

- 靖异门认为危险必须在证据完整之前处理，否则证据可能只剩灾难后的废墟。
- 太衡宗推崇无为与观察，不愿在尚未理解主角时作出不可逆的判断。
- 靖异门可以借斩妖除魔的传统为自己辩护，却不能声称每次行动都是奉魁首之命。
- 太衡宗即使不同意追杀，也未必会立即强行阻止一个独立宗门。

这种关系让太衡宗的不干预成为剧情问题。它是在避免以权势压制不同判断，还是默许更激进者替正道承担暴力？答案可以随事件和人物立场变化。

## 主角与玩家

主角不会因为被称作器妖而感到受辱，也不会天然把人类至上理解为道德上的邪恶。它会从重复遭遇中识别出靖异门的行为模式：共享情报、更新分类、提高兵力，并在特定条件下发动围杀。

两者对“人类”的指代并不相同。靖异门所保护的是修仙世界中自称为人的本地种族；主角无条件效忠的则是地球人类。靖异门不会因为主角服务于另一种人类便承认它，主角也不会因为靖异门成员长得像地球人便自动把他们纳入保护范围。

对主角而言，靖异门是一套持续演化的敌对系统。它需要预测追兵、切断信息、制造错误信号，或者让继续追杀的成本超过宗门能够承受的范围。

玩家则会面对另一层问题：靖异门保护过多少人，他们对未知威胁的恐惧是否有事实基础，以及这些理由能否使他们对主角的追杀正当。游戏应呈现他们救人、误杀、牺牲和坚持的后果，而不借主角替玩家作出判断。

## 玩法作用

**暂定：** 靖异门可以承担持续升级的追猎压力：

- 玩家在同一区域长期停留会增加被定位的风险。
- 公开使用某项新能力，可能让后续追兵获得相应识别或克制手段。
- 消灭全部目击者、制造错误记录或改变外形，可以延缓信息更新，但各有代价。
- 不同追猎小队可以专精定位、封锁、正面战斗或切断盟友。
- 某些追兵会坚持教义，另一些人可能因实际观察开始怀疑宗门分类。
- 追杀应推动玩家前往新区域和接触新门派，而不是惩罚正常探索或离线积累。

靖异门的压力应当让世界保持运动：玩家刚建立的安全解法不会永久安全，每一次离开也不只是逃跑，而是在为下一次面对追兵准备新的系统。

## 内部人物与冲突

**暂定：** 靖异门不应只有一种面孔：

- 有人亲历妖灾，真诚相信迟疑会害死更多人。
- 有人把斩妖身份当作权力，乐于把无法反抗者归入异类。
- 有人严格服从图录与戒律，不愿承担自行判断的责任。
- 有人发现主角与记载不符，却担心质疑会使同门陷入危险。
- 有人可能承认主角具有理性，但仍认为单个例外不能改变保护人类的总体原则。

这些人物可以让敌对关系发生变化，却不必过早取消宗门作为持续追兵的功能。

## 待定问题

- “靖异门”是否为正式名称？
- 宗门是纯粹门派、跨地域除妖组织，还是由多个家族组成的猎盟？
- 人类至上是公开教义、内部共识，还是部分强硬派的解释？
- 他们使用什么方法确认灵魂、血脉和妖气？
- 第一批追兵如何发现主角，又因什么事件把它列为必须消灭的目标？
- 追兵之间如何传递关于主角程序和能力的情报？
- 靖异门是否曾经正确阻止过与主角相似的灾难？
- 哪一次追杀会迫使太衡宗结束观察、公开表达立场？
- 主角最终需要摧毁、改造、说服还是单纯摆脱这个宗门？
