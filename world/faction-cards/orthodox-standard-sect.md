# 流派卡：太一宗

> 一日一周天，一境一重基。

## 身份

| 项目 | 内容 |
| --- | --- |
| 宗门 | 太一宗 |
| 根本功法 | 《周天正法》（暂名） |
| 两仪归属 | 阴：取灵 |
| 修行方向 | 稳定取灵 + 周天炼化 + 逐层固本 + 按序突破 |
| 正道地位 | 正道魁首；受各派敬重的道统与调停者 |
| 世俗关系 | 庇护衡朝，不直接统治；衡朝承认其超然地位 |
| 战斗定位 | 无明显短板、长于持久、术法齐备、稳定兑现境界实力 |
| 核心优势 | 可靠、完整、可传承、极少因单一条件失效 |
| 治世理念 | 道法自然、无为而治、不轻易直接干预凡人朝政 |
| 结构代价 | 成长缓慢；克制有时会变成迟疑、切责与不作为 |
| 核心意象 | 云海古观、周天吐纳、松风静室 |

## 一句话

太一宗没有惊世骇俗的捷径，只把取灵、炼化、固本和突破一件件做到可靠并传承千年；它不号令群雄，也不直接治理衡朝，却因深厚道统、平和门风与无为理念被各派敬为正道魁首。

## 正统功法

**暂定：** 太一宗根本功法名为《周天正法》。它遵循修仙界最容易观察和重复的道路：不以蛮力拉扯灵气，而是顺着身体与天地已经形成的走势徐徐取灵，使其沿经脉完成周天运转，逐步滤去杂质、归入丹田，再以反复温养夯实当前境界。

一个最普通的修炼循环包括：

1. 在灵气稳定之处吐纳取灵。
2. 让灵气沿经过验证的经脉路线运行。
3. 在周天中滤去不适合自身的部分。
4. 将炼化后的灵气归入丹田。
5. 反复周天，修补经脉并巩固当前境界。
6. 达到明确条件后再尝试突破。

这套功法没有隐藏的倍增条件，也不把伤害、跌境或长期等待转化为突然爆发。它的强处是每一步都有前人经验可循，修炼所得很少在战斗结束、功法中断或天道规则微调后立刻消失。

## 朴实无华

**已定：** 太一宗是其他流派的比较基准，而不是又一个依靠奇特缺陷成立的门派。

- 它取灵不如牧魂门高效，却不需要夺取灵魂。
- 它炼体不如石胎门坚固，却不会因为功法必然化为石人。
- 它的一剑不如藏锋宗蓄势后的极限，却可以连续、稳定地出手。
- 它突破不如逐境门迅速，却能长期保有境界和同境界战力。
- 它很少在某个场景拥有压倒性最优解，也很少遇到完全无法处理的场景。

太一宗门人的强弱主要来自修炼时间、根基质量、资源、经验和个人才能，而不是是否成功触发某个特殊机制。

## 为何是正道魁首

**已定：** 太一宗是正道魁首，但不是正道各派的统治者。所谓魁首，是各派对其道统、修为与公信力的共同承认。

这种地位来自长期积累：

- 功法经过多代整理，普通弟子也能沿明确路径成长。
- 从外门、内门到长老都有稳定梯队，不会因一人陨落而断绝传承。
- 剑术、法术、阵法、炼丹、医治和护山手段齐备。
- 门人较少因追求捷径造成大规模失控。
- 大争发生时，各派愿意请其长者见证盟约和主持公议。
- 天下危机出现时，它可以凭声望促成自愿联合，而非直接发号施令。

## 无为而治

**已定：** 宗门把无为同时用于修行与处世。

- 修行不是放任不管，而是不以一时欲望强迫灵气和身体超出其规律。
- 教导弟子重在示范、点拨和等待自悟，而不是用戒律替代所有判断。
- 面对宗门纷争，优先改变冲突条件，让局势回到可以共存的状态。
- 面对凡人政权，不以修为直接取得官位和统治权。
- 只有灾难已经明确且可能波及天下时，才愿意出面促成联合行动。

无为不是永远正确的答案。少作干预能够避免凭偏见伤害无辜，也可能使需要立即承担的责任被拖延，或被推给力量更弱的一方。

## 与衡朝的关系

**已定：** 衡朝位于太一宗势力边缘，是一个依赖太一庇护的凡人国家。太一为衡朝提供灾害保护、修行指导和超凡援助，衡朝提供凡间资源、人口基础与社会秩序；太一不直接统治衡朝，把土地、税赋、刑名和民生留给凡人朝廷治理。

天衡司是衡朝负责处理超凡事务的最高机构，由仙门外派弟子与凡人司员共同构成。事件超出凡间能力时，天衡司可以向太一请求支援，但案件的调查与行政处置仍由衡朝负责。

庇护关系既让衡朝得以在灵气稀薄之地维持凡人秩序，也构成太一的道德难题。主角案件同时涉及异界器物、灵气异常、社会主体与国家管辖：太一可以说这是衡朝内政，天衡司也可以说朝廷没有能力独自判断。庇护越深，责任由谁承担反而越难说清。

## 战斗表现

太一宗的战斗不依赖一次翻盘，而依赖稳定地把已有修为兑现出来。

- 起手有防护、探查和基础术法，不容易被未知手段立即击溃。
- 中段可以根据敌人切换剑术、法术、法器或阵势，但不如专精者迅速。
- 灵气循环稳定，适合持久战，也能在受伤后逐步恢复秩序。
- 同境界战力接近“根基扎实的标准值”，很少虚高，也很少突然崩塌。
- 多名弟子使用相近术语和训练体系，组成阵势时容易协作和替补。

面对太一宗时，敌人通常知道他们会做什么，却仍需要正面解决一套没有明显漏洞的完整体系。

## 正统的代价

太一宗没有致命的功法陷阱，但稳定本身也产生结构性限制：

- 每层境界都要投入时间固本，成长速度难以与极端流派相比。
- 大量门人长期修炼，需要稳定占有灵脉、丹药、土地和供养体系。
- 功法默认修士拥有灵根、经脉和感应灵气的能力，难以覆盖主角这样的异常存在。
- 宗门习惯等待事物显露完整规律，面对快速扩大的威胁可能错过干预时机。
- 不干预的立场使它不能只凭善意越过衡朝制度，却也提供了回避责任的理由。
- 门中有人把无为理解为克制，也有人借无为逃避本应承担的后果。

它的核心问题是：什么时候应当顺势而行，什么时候继续等待本身已经成为一种干预？

## 与其他门派

- 它承认石胎门炼体的威力，却会警惕其生灵来源和最终石化。
- 它尊重藏锋宗作为战略威慑的价值，也需要为藏锋的出剑建立共同指挥。
- 它把逐境门视为根基理论的反例或旁门，却无法否认对方确实能抵达更高境界。
- 它可能参与过针对牧魂门的公议，但是否亲自领导围剿仍未确定。
- 它会通过天衡司处理超出凡人能力的案件，却不接受自己是衡朝的执法工具。

这些关系让“正道”不等于所有宗门观点一致。太一宗提供的是各派愿意倾听的意见，不是所有人必须服从的裁决。

## 与主角的关系

**已定：** 主角没有灵根，也没有本土修士天然感应灵气的语义接口，因此无法直接成为《周天正法》所假设的标准修士。太一宗最初无法判断它究竟是器物、异类还是新的修行主体，但这种无法归类更可能引发观察和推演，而非立即清除。

可能的程序挑战与反哺方向仍待确定：

- 太一宗提供修仙界的基准实现，使玩家能够测量其他功法究竟偏离了什么。
- 玩家把依赖灵根直觉的步骤转化为可观测信号和明确接口。
- 主角为不同门派建立兼容测试，帮助太一宗区分“违反规律”与“不符合旧标准”。
- 太一宗反过来检验主角的程序能否在不同环境中长期稳定运行。

在正式确定前，不应为了给太一宗强加醒目机制，而削弱它作为朴素基准和无为道统的作用。

## 玩法与叙事作用

- 让玩家学习最标准的取灵、固本、突破与境界关系。
- 提供稳定但不极端的功法、物资、任务和盟友。
- 作为衡量其他门派收益与代价的基准线。
- 让庇护与自治的边界成为仙凡制度张力，而不只是背景句子。
- 让玩家面对审慎克制、庇护与及时承担责任之间的张力。
- 在正道联合行动中表现声望、调停与自愿协作的力量。

太一宗不需要在每次登场时制造惊奇。它真正应当带来的感受，是当世界中的奇异功法纷纷失控时，玩家会理解为什么无数普通修士仍愿意沿这条缓慢的石阶向上走。

## 待定问题

- 《周天正法》是正式功法名，还是整套基础传承的统称？
- 太一宗祖庭位于何处，衡朝为何处于其势力边缘？
- 它在围剿牧魂门时承担了什么角色？
- 它如何处理生灵法门：一律禁止、有限研究，还是内部秘密使用？
- 主角与太一宗之间最终对应哪一种程序挑战？
- 面对天衡司无法独自处置的主角案，它会在什么条件下越过“不直接统治”的边界？
