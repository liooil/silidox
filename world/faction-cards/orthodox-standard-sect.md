# 流派卡：太衡宗（暂名）

> 一日一周天，一境一重基。

## 身份

| 项目 | 内容 |
| --- | --- |
| 宗门 | 太衡宗（暂名） |
| 根本功法 | 《周天正法》（暂名） |
| 两仪归属 | 阴：取灵 |
| 修行方向 | 稳定取灵 + 周天炼化 + 逐层固本 + 按序突破 |
| 正道地位 | 正道魁首；受各派敬重的道统与调停者 |
| 战斗定位 | 无明显短板、长于持久、术法齐备、稳定兑现境界实力 |
| 核心优势 | 可靠、完整、可传承、极少因单一条件失效 |
| 治世理念 | 无为而治、顺势引导、以身作则、不轻易强制干预 |
| 结构代价 | 成长缓慢、依赖成熟传承；克制有时会变成迟疑与不作为 |
| 核心意象 | 清晨吐纳、周天循环、云海古观、石阶山门、松风静室 |
| 当前状态 | 正统基准、无为理念与魁首定位已定；宗门名称及主角反哺待定 |

## 一句话

这个暂名太衡宗的古老道门没有惊世骇俗的捷径，只把取灵、炼化、固本和突破一件件做到可靠、完整并传承千年；它不号令群雄，却因深厚道统、平和门风与无为理念被各派敬为正道魁首。

## 正统功法

**暂定：** 宗门的根本功法名为《周天正法》。它遵循修仙界最容易观察和重复的道路：不以蛮力拉扯灵气，而是顺着身体与天地已经形成的走势徐徐取灵，使其沿经脉完成周天运转，逐步滤去杂质、归入丹田，再以反复温养夯实当前境界。

一个最普通的修炼循环包括：

1. 在灵气稳定之处吐纳取灵。
2. 引导灵气沿已经验证的经脉路线运行。
3. 识别并排出不适合自身的杂气。
4. 将炼化后的灵气归入丹田。
5. 反复周天，修补经脉并巩固当前境界。
6. 达到明确条件后再尝试突破。

这套功法没有隐藏的倍增条件，也不把伤害、跌境或长期等待转化为突然爆发。它的强处是每一步都有前人经验可循，修炼所得很少在战斗结束、功法中断或天道规则微调后立刻消失。

## 朴实无华

**已定：** 太衡宗应当成为其他流派的比较基准，而不是又一个依靠奇特缺陷成立的门派。

- 它取灵不如牧魂门高效，却不需要夺取灵魂。
- 它炼体不如石胎门坚固，却不会因为功法必然化为石人。
- 它的一剑不如藏锋宗蓄势后的极限，却可以连续、稳定地出手。
- 它突破不如逐境门迅速，却能长期保有境界和同境界战力。
- 它很少在某个场景拥有压倒性最优解，也很少遇到完全无法处理的场景。

太衡宗门人的强弱主要来自修炼时间、根基质量、资源、经验和个人才能，而不是是否成功触发某个特殊机制。

## 为何是正道魁首

**已定：** 太衡宗是正道魁首。

**已定：** 它不是正道各派的统治者。所谓魁首，是各派对其道统、修为与公信力的共同承认。

**暂定：** 这种地位来自长期积累，而不只来自某位掌门的境界：

- 功法经过多代整理，普通弟子也能沿明确路径成长。
- 从外门、内门到长老都有稳定梯队，不会因一人陨落而断绝传承。
- 剑术、法术、阵法、炼丹、医治和护山手段齐备，可以处理大多数常见事务。
- 与各地宗门、家族和世俗政权保持长期盟约。
- 门中长者很少争夺俗世利益，因此各派愿意请他们调停争端、见证盟约。
- 当正道需要联合行动时，它依靠声望促成合作，而不是直接向其他门派下令。

它未必垄断真理，也未必每次判断都正确。它更像一条长期存在的山中道路：不要求所有人都从这里经过，却让迷失方向的人愿意回来寻找参照。

## 无为而治

**已定：** 宗门把无为同时用于修行与处世。

- 修行不是放任不管，而是不以一时欲望强迫灵气和身体超出其规律。
- 教导弟子重在示范、点拨和等待自悟，而不是用戒律替代所有判断。
- 面对门派纷争，优先疏导利益、消解敌意，让局势自行回到可以共存的状态。
- 只有灾难已经明确且可能波及天下时，才愿意出面促成联合行动。

无为不是永远正确的答案。少作干预能够避免凭偏见伤害无辜，也可能让行动更果断的宗门先把事实变成无法挽回的结果。主角遭到靖异门追杀时，这个宗门是否应该继续观察，会成为其理念必须面对的考验。

## 战斗表现

**暂定：** 太衡宗的战斗不依赖一次翻盘，而依赖稳定地把已有修为兑现出来。

- 起手有防护、探查和基础术法，不容易被未知手段立即击溃。
- 中段可以根据敌人切换剑术、法术、法器或阵势，但切换效率不如专精者。
- 灵气循环稳定，适合持久战，也能在受伤后逐步恢复秩序。
- 同境界的战力接近“根基扎实的标准值”，很少虚高，也很少突然崩塌。
- 多名弟子使用相近的术语和训练体系，组成阵势时容易协作和替补。

它提供的是可以预测的可靠战力。面对太衡宗时，敌人通常知道他们会做什么，却仍需要正面解决一套没有明显漏洞的完整体系。

## 正统的代价

太衡宗没有致命的功法陷阱，但稳定本身也产生结构性限制：

- 每层境界都要投入时间固本，成长速度难以与极端流派相比。
- 大量门人长期修炼，需要稳定占有灵脉、丹药、土地和供养体系。
- 功法默认修士拥有灵根、经脉和感应灵气的能力，难以覆盖主角这样的异常存在。
- 宗门习惯等待事物显露完整规律，面对快速扩大的威胁可能错过最佳干预时机。
- 不愿号令他派意味着它只能劝阻靖异门，除非决定亲自承担与其冲突的后果。
- 门中有人可能把无为理解为克制，也有人可能借无为回避本应承担的责任。

它的局限不是某一天必然爆发的功法灾难，而是一个持续存在的问题：什么时候应当顺势而行，什么时候继续等待本身已经成为一种选择？

## 与其他门派

**暂定：** 太衡宗可以承担连接各流派的道统与调停中心：

- 它承认石胎门炼体的威力，却会警惕其生灵来源和最终石化。
- 它尊重藏锋宗作为战略威慑的价值，也需要为藏锋的出剑建立共同指挥。
- 它把逐境门视为根基理论的反例或旁门，但无法否认对方确实能够抵达更高境界。
- 它可能参与过针对牧魂门的公议，但是否亲自领导围剿仍未确定。
- 它不认同靖异门把所有非人灵智一概视为妖邪，却也可能因证据不足而迟迟不公开阻止追杀。

这些关系让“正道”不等同于所有宗门观点一致。太衡宗提供的是各派愿意倾听的意见，不是所有人必须服从的裁决。

## 与主角的关系

**已定：** 主角没有灵根，也没有本土修士天然感应灵气的语义接口，因此无法直接成为《周天正法》所假设的标准修士。宗门最初无法判断它究竟是器物、妖邪还是新的修行主体，但这种无法归类更可能引发观察，而非立即追杀。

**开放问题：** 太衡宗与主角的核心程序挑战和反哺方向尚未确定。可能的方向包括：

- 太衡宗提供一套修仙界的基准实现，使玩家能够测量其他功法究竟偏离了什么。
- 玩家把依赖灵根直觉的步骤转化为可观测信号和明确接口，使正统功法能够被非标准主体理解。
- 主角为不同门派建立兼容测试，帮助太衡宗区分“违反规律”与“只是不符合旧标准”。
- 太衡宗反过来检验主角的程序是否只在一次偶然环境中有效，还是能够长期稳定运行。

在正式确定前，不应为了给太衡宗强加一个醒目机制，而削弱它作为朴素基准和无为道统的作用。

## 玩法与叙事作用

**暂定：** 太衡宗可以承担以下作用：

- 让玩家学习最标准的取灵、固本、突破与境界关系。
- 提供稳定但不极端的功法、物资、任务和盟友。
- 作为衡量其他门派收益与代价的基准线。
- 让玩家面对审慎克制、长期可靠与及时承担责任之间真实存在的张力。
- 在正道联合行动中表现声望、调停与自愿协作的力量。
- 让“无为”同时显露克制的智慧与可能不作为的代价。

太衡宗不需要在每次登场时制造惊奇。它真正应当带来的感受，是当世界中的奇异功法纷纷失控时，玩家会理解为什么无数普通修士仍愿意沿这条缓慢的石阶向上走。

## 待定问题

- “太衡宗”只是占位名；“冲和宗”“守一宗”“太和宗”等方向是否更符合其道门气质？
- 《周天正法》是否为正式功法名，还是对整套基础传承的统称？
- 太衡宗山门位于最大的天然灵脉，还是由多条中型灵脉共同供养？
- 它在正道中的意见具有多大影响力，又有哪些宗门会公开拒绝？
- 它在围剿牧魂门时承担了什么角色？
- 它如何处理生灵法门：一律禁止、有限研究，还是内部秘密使用？
- 主角与太衡宗之间最终对应哪一种程序挑战？
- 主角能够为这样一个本就稳定的宗门提供什么不可替代的反哺？
- 面对靖异门的追杀，它会在什么事件后结束观察并决定是否干预？
