# 流派卡：牧魂门（暂名）

> 正道打断了他们的屠戮，却没有给他们另一种活法。

| 项目 | 内容 |

| 宗门 | 牧魂门（暂名） |
| 旧日身份 | 曾被各大门派围剿的魔门 |
| 初遇状态 | 围剿刚结束不久，残部仍以人魂修炼 |
| 根本功法 | 待命名 |
| 两仪归属 | 阴：取灵 |
| 修行方向 | 抽取灵魂；后期转向规模养鸡与产业经营 |
| 核心优势 | 已知最高效的取灵法门；规模越大，修炼越快 |

## 一句话

主角初遇牧魂门时，他们刚被正道重创却仍靠人魂修炼；主角后来以规模养鸡和自动化生产替他们建立新的灵魂来源，使昔日邪法不再必须依赖猎取人类。

## 功法原理

**已定：** 牧魂门抽取活物的灵魂，并从灵魂中取得灵气。

这属于取灵，而不是生成灵气：

- 灵魂是已经存在的外部资源。
- 功法负责捕获、保存并把灵魂转化为灵气。
- 得到的灵魂越多，抽取灵气的速度越快。
- 更快的取灵速度又会加快修炼，形成不断加速的正反馈。

因此，牧魂门是已知取灵效率最高的门派。其他门派争夺灵脉、灵石和丹药时，牧魂门直接把有灵魂的活物视为灵气来源。

## 围剿与初遇

**已定：** 牧魂门过去曾大规模屠戮众生，以取得更多、更高质量的灵魂。这条道路会自行加速：

1. 抽取灵魂，得到灵气。
2. 灵魂越多，取灵越快。
3. 门人修为迅速提高。
4. 更强的门人能够屠戮和夺取更多灵魂。
5. 灵魂规模继续扩大。

他们最终成为整个修仙界的威胁，并遭到各大门派联合围剿。

**已定：** 主角与牧魂门相识时，这场围剿刚结束不久。宗门的据点、人员和灵魂储备都遭到重创，但残存门人仍在捕取并抽取人魂。他们没有主动停止旧法，只是暂时失去了继续大规模屠戮的能力。

从牧魂门的角度看，放弃人魂等于放弃唯一掌握的修炼来源；从正道与受害者的角度看，宗门的困境则是他们过去罪行的结果。这些都是世界中不同群体的判断，不是主角天然持有的人伦立场。

## 与主角的联动

**已定：** 养鸡是主角提供给牧魂门的反哺方案。主角分析功法后发现，抽魂取灵依赖灵魂的总量、质量和输入速度，但并不要求来源必须是人。人魂质量较高，鸡魂质量很低；只要鸡群能够稳定繁育并形成足够大的吞吐，低质量就可以由数量弥补。

主角并非出于对人类同类的怜悯才得出这个方案。对它而言，人魂与鸡魂是两种参数不同的输入：人魂质量较高，却稀缺、会反抗、难以稳定取得，并会持续招致正道围剿；鸡魂质量较低，却可以繁育、预测和规模化。养鸡首先提高了供应的稳定性，也降低了整套系统遭到外力摧毁的风险。

这使主角可以尝试替换功法的资源入口，而不必先改写功法本身：

1. 用小规模鸡群验证鸡魂能够被原有功法利用。
2. 比较一份人魂与大量鸡魂能够提供的灵气和取灵速度。
3. 建立种鸡、饲料、鸡舍、疫病控制和出栏周期。
4. 把抽魂、屠宰、肉品销售与灵魂储存接入同一条生产链。
5. 用自动化维持稳定吞吐，使鸡魂供应最终能够替代人魂掠夺。

这次反哺在功能上的价值不在于让抽魂更强，而在于证明牧魂门能够通过另一种资源系统活下去。它也把门派的核心难题从“如何取得更多高质量人魂”，改写为“如何维护一条规模庞大、不可中断的低质量灵魂供应链”。这是否构成道德上的改善，不由主角自动作答。

## 养鸡转型

**已定：** 在主角提出并验证方案后，牧魂门开始通过大规模养鸡寻找与其他人共同发展的道路。

鸡魂的质量远低于许多其他动物的灵魂，但鸡可以大量、稳定地繁育和饲养。牧魂门以数量抵消质量，建立新的修炼循环：

1. 管理种鸡并扩大鸡群。
2. 种植、采购和调配饲料。
3. 饲养鸡只至适合抽魂和屠宰的阶段。
4. 抽取鸡魂，供门人取灵修炼。
5. 将抽魂后的鸡肉出售。
6. 维持并继续扩大整条生产链。

同一只鸡同时提供修炼所需的灵魂与可以出售的肉品。随着生产规模扩大，宗门逐步不再依赖外出屠戮，而是依赖养殖规模、周转速度和生产管理。

**暂定：** 转型不会在主角提出方案后立即完成。鸡群规模尚小时，人魂仍然更容易提供修炼所需的力量；门内也可能有人拒绝为了低质量鸡魂放弃旧法。第一座鸡舍只是证明另一条路存在，真正停止抽取人魂需要生产能力、门内权力和外部监督同时发生变化。

## 宗门生活

**已定：** 完成养鸡转型后，牧魂门成为世俗化程度最深的门派。

门中弟子的必修内容包括：

- 养鸡
- 杀鸡
- 抽取与保存鸡魂
- 鸡肉处理和销售
- 种鸡、鸡舍与疫病管理
- 饲料采购、配比、储存和消耗管理

在这里，经营产业不是修行之外的杂务。鸡群数量、成活率、出栏速度和抽魂效率会直接决定门人的修炼速度，因此生产管理本身就是功课。

牧魂门同时扮演宗门、养殖场、屠宰场、抽魂工坊和肉品商号。它与农户、饲料商、运输者、市场和普通食客发生的联系，远比闭门修炼的宗门密切。

## 社会位置

**已定：** 在主角反哺之后，牧魂门从大规模屠戮活物的魔门，逐步转变为依靠养鸡修炼并向世俗出售鸡肉的宗门。它没有废除抽魂功法，而是用可持续繁育的鸡群替代了对外掠夺。

这种转型让多方同时获得利益：

- 牧魂门得到数量庞大且稳定的灵魂来源。
- 世俗市场得到持续供应的鸡肉。
- 养殖、饲料、屠宰、运输和销售形成长期协作。
- 其他门派不再需要面对一个靠屠戮不断加速的魔门。

它是否已经真正摆脱“魔门”身份，仍可能因地区、门派和个人立场而有不同答案。

## 认知与偏差

**已定：** 初遇时的牧魂门习惯于追逐高质量人魂，把杀死更强、更多的人视为功法增长最直接的道路。主角提供了另一种观察尺度：单个灵魂的质量并不是唯一指标，稳定供给、总体数量和单位时间吞吐同样可以决定修炼速度。

转型后的牧魂门清楚鸡魂质量低而数量占优。他们解决的是资源来源、规模和吞吐，而不是灵气生成。从主角的视角看，这是一条带有正反馈的自动化生产线：饲料与时间产生鸡群，鸡群提供灵魂和肉品，灵魂提高取灵吞吐，肉品则支撑生产链继续运转。功法的强弱已经无法只从单个修士身上判断，必须观察整个系统的产能。

## 玩法轮廓

**暂定：** 牧魂门的玩法可以从危险的初遇逐步转向生产与自动化：

- 玩家首先需要查明残部仍在抽取人魂，并理解功法为何让他们难以主动停手。
- 主角只提供观测结果、系统方案与可预见后果；这次转型在伦理上意味着什么，由玩家判断。
- 玩家用第一批鸡进行替代实验，证明低质量灵魂能够通过数量弥补。
- 玩家规划饲料、鸡舍、种群、屠宰和抽魂之间的比例。
- 鸡魂质量低，必须依靠稳定吞吐和规模扩张取得优势。
- 肉品销售带来维持或扩大养殖所需的资源。
- 疫病、饲料短缺、运输中断和价格变化会直接影响修炼速度。
- 过度追求短期抽魂数量可能破坏繁育能力，使正反馈反向崩溃。
- 梯形图可以控制喂食、分栏、出栏、抽魂和库存报警，让宗门修炼真正成为工业流程。

这个流派的成长感来自生产链逐渐加速：最初每一只鸡都很重要，后来真正重要的是系统每个时辰能稳定处理多少鸡魂。

## 冲突与钩子

**钩子：** 主角不会替玩家裁定牧魂门是否值得帮助。转型从一开始就伴随着旧罪、内部阻力和新的伦理问题：

- 有些残部是否会一面加入养鸡，一面秘密保存或继续猎取人魂？
- 正道是否愿意相信一座鸡舍足以证明魔门已经改变？
- 曾经的受害者是否有义务为了未来的和平接受这次转型？
- 抽魂之后，鸡的灵魂究竟是被消耗、破碎，还是仍能进入轮回？
- 鸡魂质量低是物种决定，还是与寿命、经历和饲养方式有关？
- 为提高魂质而改善鸡的生活，会不会反而增加每只鸡的价值？
- 牧魂门是否仍保存着旧时代夺取的人或妖兽灵魂？
- 其他门派一边谴责抽魂，一边购买鸡肉，是否构成新的利益同盟？
- 如果鸡群发生大疫，门人的修炼和世俗肉食供应会不会同时崩溃？
- 当产业规模足够大时，牧魂门究竟是宗门、商号，还是控制一方民生的世俗势力？

## 待定问题

- 宗门当前名称、旧日魔门名称与根本功法分别是什么？
- 灵魂数量如何提高抽取速度：并行抽取、功法增幅，还是灵魂之间的共鸣？
- 抽魂是否必然导致死亡，还是屠宰只是产业流程的一部分？
- 鸡魂能保存多久，储存是否需要特殊阵法或容器？
- 门人是分别持有鸡魂，还是共享宗门的灵魂储备？
- 各大门派为何接受或容忍其转型，是否存在正式契约和监管？
- 玩家如何看待主角对牧魂门功法的接触、利用与反哺？
- 界面应当呈现哪些事实和后果，才能让玩家判断，而不借主角之口预设答案？
